Email Automation

A working automation project that turns a repetitive recruiter-email review process into a structured backend workflow for retrieval, filtering, document generation, archiving, and delivery.

Start with the problemExamine the architecture
Why it exists

From manual review to a repeatable workflow

The original process required roughly 12 hours of manual review. A Python prototype validated the automation approach and reduced the workflow to about 90 minutes. The Java version rebuilds that proven workflow using a service-oriented Spring Boot design.

Read the project story →
Engineering focus

More than a file converter

The application coordinates Gmail authentication and retrieval, content extraction, filtering, TXT/DOCX generation, ZIP processing, outbound delivery, and workflow results while keeping responsibilities separated.

Review engineering decisions →

Workflow at a glance

Gmail label→Retrieve→Extract→Filter→TXT / DOCX→ZIP→Outbound email

The application processes messages already placed in a designated Gmail label. It does not automatically reorganize the user's Inbox.
