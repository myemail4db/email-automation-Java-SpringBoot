Setup & Run

From a fresh clone, configure Gmail OAuth and application properties, start Spring Boot, verify connectivity, then run Export and Send as two separate user actions.

1. Build and run

mvn clean test
mvn spring-boot:run

2. Verify the application

http://localhost:8080/api/health
http://localhost:8080/api/gmail/status

3. Export

The optional format parameter defaults to text.

http://localhost:8080/api/export
http://localhost:8080/api/export?format=text
http://localhost:8080/api/export?format=word

4. Manually review the files

Open processed_review/. Review each TXT/DOCX file, make any desired edits, and save it. This is an intentional stop in the workflow.

5. Send

The optional format parameter defaults to text.

http://localhost:8080/api/send
http://localhost:8080/api/send?format=text
http://localhost:8080/api/send?format=word

6. Verify the result

After a successful send, individual files should be in sent_archive_email/, the exact ZIP should be in sent_archive_zip/, and ready_to_send/ should be empty. Previously sent Gmail IDs should instead move to duplicate/ and should not produce another outgoing email.

Troubleshooting

If OAuth or Gmail access fails, use the Gmail & OAuth Setup guide. If a workflow stage fails, inspect the returned status message and application log before changing files manually.
