Setup & Run

From a fresh clone to a verified local workflow. Complete the steps in order so each layer can be tested before moving to the next.

1. Prerequisites

  • Java 17
  • Maven
  • Git
  • A Google account with Gmail
  • A Google Cloud project

2. Clone the project

git clone <repository-url>
cd email-automation-Java-SpringBoot/backend

3. Set up Gmail OAuth

This is required before Gmail endpoints can work. The guide covers Google Cloud, Gmail API, OAuth consent, Desktop credentials, the exact credentials.json location, private properties, first authorization, generated tokens, and troubleshooting.

Open Gmail & OAuth Setup →

4. Review application configuration

Configure Gmail labels, local directories, ZIP naming, default export format, source account, and recipient before running the workflow.

Customize the Application →

5. Build and run

mvn clean compile
mvn spring-boot:run

The application runs at http://localhost:8080.

6. Verify one layer at a time

StepCommand
Spring Bootcurl http://localhost:8080/api/health
Gmail OAuth/connectivitycurl http://localhost:8080/api/gmail/status
Gmail retrievalcurl http://localhost:8080/api/gmail/emails
TXT workflowcurl "http://localhost:8080/api/export?format=text"
DOCX workflowcurl "http://localhost:8080/api/export?format=word"
Use HTTP locally. The current Spring Boot development server is configured on port 8080 without local HTTPS configuration, so use http://localhost:8080.

7. If something fails

Start with the first verification checkpoint that fails. The Gmail & OAuth Setup page includes symptom-based troubleshooting for credentials, test users, authorization, tokens, ports, labels, 401/403 responses, and private configuration.

Documentation website

Open docs/index.html in a browser. Supporting pages are under docs/pages/.
