Developer guide

Setup & Run

Prerequisites

  • Java 17
  • Maven
  • Git
  • A Google account
  • A Google Cloud project with Gmail API enabled
  • OAuth credentials for Gmail API access

Clone and run

git clone <repository-url>
cd email-automation/backend

mvn clean compile
mvn spring-boot:run

The application runs locally at http://localhost:8080.

Verify the backend

curl http://localhost:8080/api/health

Application configuration

Spring Boot configuration is stored under backend/src/main/resources/. For example:

email.export.output-dir=processed_review

OAuth safety

Do not commit credentials or tokens. Gmail OAuth client credentials, access tokens, and refresh tokens contain sensitive information and should remain outside source control.

Documentation website

Open docs/index.html in a browser. It is intentionally the only HTML file directly under docs/; supporting pages are kept in docs/pages/ so the starting point is obvious.
