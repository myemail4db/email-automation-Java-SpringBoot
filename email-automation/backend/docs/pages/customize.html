Configuration reference

Customize the Application

Change Gmail labels, local directories, ZIP naming, export format, and user-specific email settings without changing Java source code.

Where the configuration files go

backend/
└── src/
    └── main/
        └── resources/
            ├── application.properties
            ├── application-private.properties
            └── credentials.json

application.properties is the normal application configuration. application-private.properties contains user-specific email addresses and is excluded from Git. credentials.json is the downloaded Google Desktop OAuth client and is also excluded from Git.

application-private.properties

Create this file locally under backend/src/main/resources/:

email.gmail.source-account=your-gmail-address@example.com
email.send.recipient=destination-address@example.com
PropertyWhat to enter
email.gmail.source-accountThe Gmail account used by this installation/workflow.
email.send.recipientThe destination address for outbound delivery.
Private files: Do not commit application-private.properties, credentials.json, or tokens/. A fresh clone requires each user to create/download their own private files.

Common customizations

Process a different Gmail label

email.gmail.source-label=my_source_label

If you change the workflow labels, make sure the corresponding labels exist in the Gmail account.

Change the local review directory

email.files.processed-dir=my_review_directory

Change where ZIP files are created

email.files.zip-dir=my_zip_directory

Change the ZIP prefix

email.files.zip-prefix=my_batch

Use DOCX as the default

email.export.default-format=word

The current workflow endpoint supports text and word.

Change the Gmail account or recipient

Edit only your local application-private.properties.
