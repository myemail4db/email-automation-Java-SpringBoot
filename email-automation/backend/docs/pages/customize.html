application.properties

Use this file for normal application behavior and workflow settings.

Gmail processing label

email.gmail.label=for_friend

Change for_friend to an existing Gmail label containing the messages you want the application to process.

Export directory

email.export.output-dir=processed_review

Change the value to another directory or path that the application has permission to write to.

Default export format

email.export.default-format=text

Supported values documented by the current application are text for TXT output and word for DOCX output.

ZIP export directory

email.zip.export-dir=ready_to_send

Controls where generated ZIP archives are written. ZIP processing is currently in development.

Sent archive directory

email.sent.folder.name=send_archive

Controls the directory intended for archive handling after outbound processing. Final outbound handling is currently in development.

application-private.properties

Use this file for values specific to the user's email workflow.

email.gmail.source-account=your-email@example.com
email.send.recipient=destination@example.com

Source Gmail account

email.gmail.source-account should contain the Gmail account authorized for this installation.

Outbound recipient

email.send.recipient should contain the address that will receive the completed archive when outbound email delivery is completed.

Keep private configuration private. Do not commit application-private.properties, OAuth client credentials, authorization tokens, access tokens, refresh tokens, passwords, or other private authentication information to Git.

Common configurations

Use DOCX by default

email.export.default-format=word

Use another Gmail label

email.gmail.label=my_processing_label

Use another review directory

email.export.output-dir=my_review_folder

Send to another recipient

In application-private.properties:

email.send.recipient=destination@example.com

Before running the application

  1. Confirm the configured Gmail label exists.
  2. Confirm the source Gmail account is the account authorized through OAuth.
  3. Confirm configured directories are writable.
  4. Use text or word for the supported export format.
  5. Keep private configuration and OAuth files out of source control.
  6. Remember that ZIP and outbound email stages are still in development.
