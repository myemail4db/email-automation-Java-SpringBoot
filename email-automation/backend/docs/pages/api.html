Email Automation  /  API
REST endpoints

API

The Spring Boot backend exposes REST endpoints for health checks, Gmail inspection, Export, and Send. Export and Send are intentionally separate because the user manually reviews the generated files between them.

Endpoint summary

MethodEndpointPurpose
GET/api/healthApplication health check.
GET/api/gmail/statusVerify Gmail connectivity/status.
GET/api/gmail/emailsInspect messages returned by the Gmail integration.
GET/api/emailsEmail controller endpoint available in the current application.
GET/api/exportExport messages to TXT or DOCX for manual review. The optional format parameter defaults to text.
GET/api/sendSend manually reviewed files. The optional format parameter defaults to text.

Export

http://localhost:8080/api/export
http://localhost:8080/api/export?format=text
http://localhost:8080/api/export?format=word

/api/export and /api/export?format=text are equivalent with the current default configuration.

Manual review

After Export, open the files in processed_review/, review or modify them, and save the changes. Send does not start automatically.

Send

http://localhost:8080/api/send
http://localhost:8080/api/send?format=text
http://localhost:8080/api/send?format=word

/api/send defaults to text. During Send, duplicate Gmail IDs are removed from the outgoing batch before ZIP creation.
