Email Automation  /  API
REST interface

API

The backend exposes REST endpoints for application health, Gmail integration, and workflow processing. The API provides a simple way to inspect the application during development and exercise the workflow without requiring a frontend.

MethodEndpointPurpose
GET/api/healthVerify that the Spring Boot application is running.
GET/api/gmail/statusValidate Gmail integration/connectivity.
GET/api/gmail/emailsRetrieve messages through the Gmail integration.
GET/api/exportStart the email export workflow using the requested format.

Example

curl http://localhost:8080/api/health

# Example export request
curl "http://localhost:8080/api/export?format=text"

The exact workflow response can evolve while Version 1 reporting is being completed.

Java 17 · Spring Boot · Gmail API · OAuth 2.0 · Apache POI · Maven
