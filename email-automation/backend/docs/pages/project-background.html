Project Background

From manual processing to a repeatable workflow

The project began with a repetitive recruiter-email review process that required roughly 12 hours of manual work. A Python implementation first proved the automation concept and reduced the effort to about 90 minutes.

The Java 17 / Spring Boot version rebuilds the proven workflow with clearer service boundaries, REST entry points, workflow reporting, safer duplicate handling, and explicit artifact lifecycle management.

Current end-to-end workflow

Gmail source label
      ↓
EXPORT → TXT / DOCX in processed_review/
      ↓
USER MANUAL REVIEW AND MODIFICATION
      ↓
SEND
      ↓
Gmail-ID duplicate check
  ├── already sent → duplicate/
  └── new → ZIP → Gmail delivery
                    ↓
          sent_archive_email/
          sent_archive_zip/
Current milestone: the core Java workflow is implemented and runtime-validated. The next feature is a command-line interface that reuses the same service layer.
