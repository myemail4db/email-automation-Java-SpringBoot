Project Background

Why this project exists

The project began with a repetitive email-review workflow. Recruiter and job-opportunity emails had to be opened, reviewed, cleaned up, organized, and prepared for later review. The manual process took roughly 12 hours.

A Python implementation was created first to prove that the workflow could be automated. That version reduced the manual review effort to approximately 90 minutes.

Key result: the Python version validated the workflow. The Java project is not a speculative rewrite. It rebuilds a workflow that had already demonstrated practical value.

Why rebuild it in Java?

The Java 17 / Spring Boot implementation explores a more structured backend architecture. Instead of placing the complete process in one script, responsibilities are separated into services for authentication, retrieval, extraction, filtering, file generation, ZIP creation, outbound email, and orchestration.

User control

The application processes emails that the user has already placed in a designated Gmail label. It intentionally does not automatically move or reorganize Inbox messages.

Version 1 goal

Version 1 aims to reproduce the proven core workflow in Java, then establish a foundation for future enhancements without requiring a major architectural redesign.
