System design

Architecture

Email Automation is a Java 17 Spring Boot application built around a REST-driven workflow. EmailExportService is the primary orchestrator. Specialized services own individual responsibilities so the end-to-end flow remains understandable without turning one class into a kitchen sink.

Component flow

ExportController
      │
      ▼
EmailExportService
  ├── GmailService ── GmailAuthService ── Gmail API
  ├── EmailBodyExtractorService
  ├── TextFilterService
  ├── FileExportService ── TXT / DOCX
  ├── ZipExportService       [in development]
  └── EmailSendService ── Gmail API [in development]

Responsibility boundaries

ComponentResponsibility
GmailAuthServiceOAuth configuration, authorization flow, local token storage, authenticated Gmail client.
GmailServiceGmail connectivity and message retrieval from the configured processing label.
EmailBodyExtractorServiceConverts Gmail message structures into the application's internal email content.
TextFilterServiceNormalizes and cleans content before export.
FileExportServiceCreates TXT and DOCX output and handles filenames.
ZipExportServicePackages generated files into an archive.
EmailSendServiceSends the completed archive through Gmail.
EmailExportServiceCoordinates the user-facing business workflow.
