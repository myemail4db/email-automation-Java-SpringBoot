Configuration reference

Customize the Application

Most workflow behavior can be changed through Spring Boot properties without editing Java source code.

Gmail workflow labels

PropertyExamplePurpose
email.gmail.source-labelfor_friendMessages selected for Export.
email.gmail.success-labelfor_friend/processed_reviewGmail label applied after successful export.
email.gmail.fail-labelfor_friend/errorGmail label used for export failures.

Local directories

PropertyExamplePurpose
email.files.processed-dirprocessed_reviewTXT/DOCX files waiting for manual review and Send.
email.files.zip-dirready_to_sendTemporary ZIP staging directory.
email.files.archive-dirsent_archive_emailIndividual files confirmed as sent. Used for Gmail-ID duplicate detection.
email.files.zip-archive-dirsent_archive_zipExact ZIP packages successfully sent.
email.files.duplicate-dirduplicateFiles rejected because their Gmail ID was already sent.
email.files.zip-prefixjob_batchZIP filename prefix.

Export default

email.export.default-format=text

Supported workflow formats are text and word. Omitting format from /api/export uses this configured default. /api/send currently defaults its optional format parameter to text.

Private configuration

The outbound recipient is supplied through private configuration using email.gmail.recipient. Keep private properties, OAuth credentials, tokens, logs, generated review files, duplicates, and sent archives out of source control.

Important: if Gmail label names are changed, create or verify the corresponding labels in the Gmail account before running Export.
